    토큰 붙여넣기

    Meta 개발자 화면에서 받은 토큰을 여기에만 붙여넣어 주세요. 채팅·메신저로 보내지 마세요.

    그 계정 토큰이 맞을 때만 저장돼요.
    토큰 받는 법
    1. 인스타: for_ins 인스타 설정 화면 → 2. 액세스 토큰 생성 → ggul.ggul.zip 옆 토큰 생성 → 뜬 창에서 확인 후 복사
    2. 스레드: 폰 스레드 앱에서 꿀꿀집 인스타로 프로필을 만들고 공개로 둔 뒤, for_ins Threads 테스터 추가 → 스레드 설정 › 계정 › 웹사이트 권한 › 초대 수락 → for_ins 스레드 설정 화면 › 사용자 토큰 생성기
    3. 여기 붙여넣고 저장 → 바로 게시물·통계를 모아요. 그 뒤로는 6시간마다 자동으로 모으고, 토큰은 7일마다 자동 연장돼요.
