토큰 붙여넣기

Meta 개발자 화면에서 받은 토큰을 여기에만 붙여넣어 주세요. 채팅·메신저로 보내지 마세요.

저장 전에 그 계정 토큰이 맞는지 확인해요. 남의 토큰은 저장되지 않아요.
토큰 받는 법
  1. 인스타: for_ins 인스타 설정 화면 → 2. 액세스 토큰 생성 → 계정 옆 토큰 생성 → 뜬 창에서 확인 후 토큰 복사
  2. 스레드: for_ins 스레드 설정 화면 → 아래 사용자 토큰 생성기 → 계정 옆 액세스 토큰 생성 (스레드 프로필이 공개여야 해요)
  3. 위 토큰 붙여넣기에 계정을 고르고 붙여넣은 뒤 저장 → 계정 카드의 올리기 직전까지 시험을 눌러 확인

토큰은 60일짜리예요. 매일 새벽 4시 20분에 확인해서 7일마다 자동으로 다시 60일로 연장돼요.
