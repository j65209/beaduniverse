# 카카오톡 연결 매뉴얼 (오피스앱 → 카카오톡 알림)

> 목적: 오피스앱에서 생기는 일(연차 신청 · 업무 요청 · 퇴사 처리 · 시스템 멈춤 등)을 **카카오톡으로 받기**.
> 확인한 날: 2026-11-15 (카카오 · 발송 업체 정책은 자주 바뀌니 진행할 때 화면 문구를 우선해 주세요).
> 위험도: **0** — 전부 카카오 공식 기능만 씁니다.

---

## 먼저 알아 둘 것 — 단톡방에는 못 올립니다

카카오 공식 API 에는 **단톡방(그룹 채팅)에 자동으로 글을 올리는 기능이 없습니다.**
공식으로 가능한 건 아래 세 가지이고, 모두 **1:1** 로 갑니다.

| | ① 나에게 보내기 | ② 알림톡 | ③ 채널 챗봇 |
|---|---|---|---|
| 받는 곳 | 연결한 카카오 계정의 **「나와의 채팅」** | 직원 각자 **휴대폰 번호**로 (오피스앱 직원 연락처에 이미 있음) | 회사 카카오톡 채널과 1:1 대화방 |
| 보내는 이름 | 내 계정 | 회사 채널 (예: 비드유니버스) | 회사 채널 |
| 비용 | 무료 | 건당 약 6~13원 (VAT 별도, 업체마다 다름) | 무료 (서버는 지금 쓰는 Supabase) |
| 준비 기간 | 30분 | 3~7일 (사업자 인증 · 템플릿 검수) | 1~2주 |
| 사업자등록증 | 필요 없음 | 필요 | 필요 |
| 어울리는 일 | 대표님 알림 — 새 연차 신청, 업무일지 미작성, 맥미니 멈춤 | 직원 알림 — 연차 승인, 업무 요청 도착, 공지 | 직원이 물어보기 — "내 남은 연차?" |

**추천 순서:** ① 부터 (오늘 바로, 무료) → 직원에게도 보내야 하면 ② 추가 → ③ 은 필요해질 때.

- 「친구에게 보내기」 API 는 앱 안의 회원끼리 쓰는 기능이라 자동 알림 용도는 검수에서 반려되고, 하루 보낼 수 있는 양도 적어서 회사 알림에는 맞지 않습니다.
- PC 카톡 자동 조작, 안드로이드 「메신저봇」 같은 비공식 방법은 카카오 운영정책 위반으로 **계정이 정지될 수 있어 권하지 않습니다.**
- 단톡방 공지와 비슷한 효과가 필요하면 ② 알림톡을 직원 전원에게 보내면 됩니다.

## 공통 — 키는 어디에 두나

이 저장소는 Public 이라 **키 · 토큰을 `index.html` 이나 커밋에 절대 넣지 않습니다.**

```
오피스앱(브라우저)  →  Supabase 엣지 함수 kakao-notify (키 보관 · 토큰 자동 갱신)  →  카카오
```

- 키는 **Supabase 대시보드 → 프로젝트 「브라이트비드오피스」 → Edge Functions → Secrets** 에만 넣습니다.
  (지금 쓰는 sns · ggul-links 엣지 함수와 같은 방식)
- 키 값을 채팅창에 붙여넣지 마세요. 이름만 맞춰 Secrets 에 넣으면 Claude 가 함수에서 꺼내 씁니다.

## ① 나에게 보내기 — 대표님 카톡으로 알림

### 준비물
- 알림 받을 카카오 계정 (대표님 본인 계정)

### Step 1. 카카오 디벨로퍼스 앱 만들기 (10분)
1. https://developers.kakao.com → 알림 받을 계정으로 **로그인**
2. **내 애플리케이션 → 애플리케이션 추가하기**
   - 앱 이름: `비드유니버스 오피스 알림`
   - 회사명: `주식회사 비드유니버스` · 카테고리: 비즈니스
3. 만든 앱 → **앱 키** 에서 **REST API 키** 를 확인 (Step 4 에서 씀)

### Step 2. 카카오 로그인 · 메시지 권한 켜기 (10분)
1. **카카오 로그인 → 활성화 설정: ON**
2. **Redirect URI** 에 아래 주소 하나 등록
   ```
   https://ckyjkxbqsyjoqpuqwoce.supabase.co/functions/v1/kakao-notify/oauth
   ```
   (Claude 가 만들 연결용 주소입니다. 아직 없어도 먼저 등록해 두면 됩니다)
3. **동의항목 → 「카카오톡 메시지 전송 (talk_message)」 → 선택 동의(또는 이용 중 동의)** 로 설정
4. **보안 → Client Secret → 코드 생성 → 활성화 상태: 사용함**

> 메뉴 이름은 카카오 화면 개편에 따라 조금 다를 수 있습니다. 「카카오 로그인」 「동의항목」 「Redirect URI」 「Client Secret」 네 단어로 찾으면 됩니다.

### Step 3. 키를 Supabase Secrets 에 넣기 (3분)

| Secret 이름 | 넣을 값 |
|---|---|
| `KAKAO_REST_API_KEY` | Step 1-3 의 REST API 키 |
| `KAKAO_CLIENT_SECRET` | Step 2-4 의 Client Secret 코드 |

### Step 4. Claude 에게 마무리 맡기기
새 대화에서: **"카카오 나에게 보내기 연결 마무리해줘: github.com/j65209/beaduniverse"**
→ Claude 가 엣지 함수 `kakao-notify` 를 만들고 오피스앱 이벤트(어떤 알림을 받을지)에 붙입니다.

### Step 5. 처음 한 번 연결하기 (1분)
1. Claude 가 알려 주는 **연결 링크**를 대표님 휴대폰(카톡 로그인된 상태)에서 열기
2. 카카오 동의 화면 → **「카카오톡 메시지 전송」 동의** → 「연결 완료」 화면
3. 테스트 메시지가 카톡 **「나와의 채팅」** 에 오면 끝

- 대표님 두 분이 모두 받으려면 Step 5 를 각자 계정으로 한 번씩 합니다 (안 되면 디벨로퍼스 앱 → 멤버에 그 계정을 추가한 뒤 다시).
- 토큰은 함수가 알아서 갱신합니다 (액세스 토큰 6시간 · 리프레시 토큰 2개월, 갱신할 때 새 리프레시 토큰이 나옴).
  **두 달 넘게 한 번도 갱신이 안 되면 끊기므로** 함수가 정기적으로 갱신해 두게 만듭니다. 끊기면 Step 5 만 다시 하면 됩니다.

## ② 알림톡 — 직원 휴대폰으로 알림

알림톡은 **정보성 메시지만** 보낼 수 있고(광고 문구 X), 문구를 미리 **템플릿으로 카카오 검수**를 받아야 합니다.
직원 번호는 오피스앱 **인사팀 → 직원 연락처**(`staff_phones`)에 이미 있어서 그대로 씁니다.

### 준비물
- 사업자등록증 (주식회사 비드유니버스)
- 관리자 휴대폰 (인증용)

### Step 1. 카카오톡 채널 만들고 비즈니스 인증 (심사 보통 영업일 며칠)
1. https://business.kakao.com → 로그인 → **카카오톡 채널 만들기**
   - 채널 이름: `비드유니버스` · 검색용 아이디: 예) `@beaduniverse`
2. 채널 관리자센터 → **비즈니스 인증 신청** → 사업자등록증 업로드
   (인증된 **비즈니스 채널**이어야 알림톡을 보낼 수 있습니다)

### Step 2. 발송 업체 가입 + 채널 연동 (30분)
알림톡은 카카오 공식 딜러사를 통해 보냅니다. 예시는 **솔라피** (다른 곳도 같은 흐름).
1. https://solapi.com 회원가입 → 사업자 정보 입력
2. **카카오 채널 연동(발신프로필 등록)** → Step 1 의 채널 검색용 아이디 + 관리자 휴대폰 인증
3. 연동이 끝나면 나오는 **발신프로필 ID(pfId)** 를 확인
4. **선불 충전** — 예: 1만 원이면 알림톡 약 700~1,500건 (업체 · 발송량별 단가 차이)

> 업체마다 단가가 2배까지 차이 납니다(2026년 기준 건당 약 6~13원, VAT 별도). 계약 전 월 발송량별 단가를 비교해 보세요.

### Step 3. 템플릿 등록 → 카카오 검수 (보통 1~3 영업일, 정해진 기간 없음)
발송 업체 화면에서 템플릿을 만들고 **검수 요청**합니다. `#{ }` 안은 보낼 때 바뀌는 칸입니다.

**연차 신청 알림** (관리자에게)
```
[비드유니버스 오피스]
#{이름}님이 연차를 신청했어요.

· 날짜: #{날짜}
· 종류: #{종류}

오피스앱에서 확인해 주세요.
```
**업무 요청 도착** (받는 직원에게)
```
[비드유니버스 오피스]
#{보낸사람}님이 업무를 요청했어요.

· 내용: #{내용}

업무일지에서 확인해 주세요.
```
- 버튼: **웹링크** 「오피스 열기」 → `https://beaduniverse.kr/office/`
- 등록한 템플릿은 수정이 안 되고 새로 등록해야 합니다. 보낼 때 문구가 승인된 템플릿과 한 글자라도 다르면 실패합니다.
- 광고처럼 보이는 표현(할인, 이벤트 등)이 들어가면 반려됩니다.

### Step 4. 키를 Supabase Secrets 에 넣기

| Secret 이름 | 넣을 값 |
|---|---|
| `SOLAPI_API_KEY` | 솔라피 → 개발/연동 → API Key |
| `SOLAPI_API_SECRET` | 같은 곳의 API Secret |
| `KAKAO_PF_ID` | Step 2-3 의 발신프로필 ID |
| `ALIMTALK_TPL_LEAVE` | 승인된 「연차 신청 알림」 템플릿 ID |
| `ALIMTALK_TPL_REQUEST` | 승인된 「업무 요청 도착」 템플릿 ID |

### Step 5. Claude 에게 마무리 맡기기
**"알림톡 연결 마무리해줘: github.com/j65209/beaduniverse"** → 엣지 함수에 알림톡 발송을 붙이고, 누구에게 어떤 일로 보낼지 정한 뒤 테스트 1건.

## ③ 채널 챗봇 — 직원이 카톡으로 물어보기 (나중에)

직원이 회사 채널과 1:1 대화로 "내 남은 연차?" 같은 걸 물으면 오피스앱 데이터로 답하는 방식입니다.
- ② 의 비즈니스 채널이 있어야 합니다.
- 카카오 **챗봇 관리자센터**에서 봇을 만들고 채널에 연결 → **스킬 서버** 주소에 Supabase 엣지 함수를 등록.
- 스킬 응답은 **5초 안에** 와야 합니다 (콜백을 켜면 더 길게 가능).
- 회사가 만든 봇을 단톡방에 넣는 공식 방법은 확인되지 않았습니다 (카카오 자체 ChatGPT 챗봇만 그룹방 지원, 2026-06 발표).
- 필요해지면 "카카오 채널 챗봇 만들어줘" 로 요청하세요.
