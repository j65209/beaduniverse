    발송 서버 업데이트

    처음에 만든 Apps Script 프로젝트의 코드만 바꾸면 돼요. 웹 앱 URL·연결은 그대로예요.

    1새 서버 코드 복사

    지금 연결에 쓰는 발송 키가 그대로 들어가요

    2Apps Script에서 바꾸기 (보내는 계정으로)

    1. script.google.com → 처음에 만든 메일 발송 프로젝트 열기
    2. 코드 전부 지우고 붙여넣기 → 저장 (Ctrl+S)
    3. 위쪽 함수 선택에서 setup 고르고 ▶ 실행 → 권한 요청이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용 (자동 실행 권한이 추가돼요). 실행하면 지금까지 지메일로 보낸 메일을 기록 시트로 가져오고, 앞으로도 1시간마다 자동으로 모아요
    4. 배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포
    5. 이 화면 새로고침
    💡 권한 창에서 「현재 파일을 열 수 없습니다」가 뜨면 크롬에 구글 계정이 여러 개 로그인돼 있어서 그래요 → 시크릿 창(Ctrl+Shift+N)에서 보내는 계정 하나만 로그인해서 다시 해 주세요. 권한 목록이 나오면 모두 선택을 꼭 체크.

    1발송 서버 코드 복사

    이 PC 전용 발송 키가 들어간 코드예요

    2보내는 구글 계정에 서버 만들기 (처음 한 번)

    1. 보내는 계정(brightbeed@gmail.com)으로 로그인한 상태에서 script.new 열기
    2. 원래 있던 코드를 지우고 복사한 코드 붙여넣기 → 저장 (Ctrl+S)
    3. 오른쪽 위 배포 → 새 배포 → 유형 선택 톱니바퀴에서 웹 앱
    4. 다음 사용자 인증 정보로 실행: 나 · 액세스 권한: 모든 사용자 → 배포
    5. 권한 요청이 뜨면 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용 (내 계정 스크립트라 뜨는 경고예요)
    6. 나온 웹 앱 URL 복사
    연결하면 지금까지 지메일로 보낸 메일도 기록 시트로 자동으로 모으고, 그 뒤로는 1시간마다 새로 보낸 메일을 이어 붙여요.
