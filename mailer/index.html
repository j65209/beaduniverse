    발송 서버 업데이트

    처음에 만든 Apps Script 프로젝트의 코드만 바꾸면 돼요. 웹 앱 URL·연결은 그대로예요.

    1새 서버 코드 복사

    지금 연결에 쓰는 발송 키가 그대로 들어가요

    2Apps Script에서 바꾸기 (보내는 계정으로)

    1. script.google.com → 처음에 만든 메일 발송 프로젝트 열기
    2. 코드 전부 지우고 붙여넣기 → 저장 (Ctrl+S)
    3. 위쪽 함수 선택에서 setup 고르고 ▶ 실행 → 권한 요청이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용 (자동 실행 권한이 추가돼요). 실행하면 지금까지 지메일로 보낸 메일을 기록 시트로 가져오고, 앞으로도 1시간마다 자동으로 모아요
    4. 배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포
    5. 이 화면 새로고침
    💡 권한 창에서 「현재 파일을 열 수 없습니다」가 뜨면 크롬에 구글 계정이 여러 개 로그인돼 있어서 그래요 → 시크릿 창(Ctrl+Shift+N)에서 보내는 계정 하나만 로그인해서 다시 해 주세요. 권한 목록이 나오면 모두 선택을 꼭 체크.

    메일 발송 연결 설정

    메일은 아래에서 만드는 발송 서버의 구글 계정으로 나가요. 이 연결 정보는 이 브라우저에만 저장돼요.

    🔁 보내는 계정 바꾸기

    예) brightbeed@gmail.com → brightbeed@bead-uni.com. 지금까지의 발송 기록 시트를 새 계정이 그대로 이어서 써서, 이미 보낸 곳에 다시 보내지 않아요.

    ➕ 보조 계정 — 메인과 한 통씩 번갈아 보내기

    메인·보조 계정이 한 통씩 번갈아 보내요. 한쪽 한도가 다 차면 남은 쪽으로 이어 보내요. 발송 기록 시트를 같이 써서 이미 보낸 곳에 다시 보내지 않아요.
    보조 계정
    —
    보조 남은 한도
    —
    1. 새 발송 키 + 지금 기록 시트 주소가 들어간 코드예요
    2. 보조로 쓸 계정(예: brightbeed@gmail.com)으로 그 계정의 메일 발송 서버 프로젝트를 열고 코드를 전부 바꿔 붙여넣기 → 저장 → setup ▶ 실행 (프로젝트가 없으면 script.new)
    3. 배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포 (새 프로젝트면 새 배포 → 웹 앱 · 나 · 모든 사용자)
    4. 웹 앱 URL 붙여넣고 연결

    💻 다른 PC에서도 쓰려면

    연결 코드를 복사해서 다른 PC의 이 화면 「연결 코드」 칸에 붙여넣으면 바로 연결돼요. 보조 계정이 붙어 있으면 그것도 같이 연결돼요.

    🔁 → 새 계정으로 옮기기

    1. 지금 계정으로 발송 기록 시트를 열고 공유 → 새 계정 주소 → 편집자로 공유해 주세요 (이걸 해야 예전 기록을 이어서 써요)
    2. 구글 드라이브의 「브라이트비드 메일 첨부」 폴더도 같은 방법으로 공유 (안 하면 첨부파일을 새로 올려야 해요)
    3. 아래 1~3을 새 계정으로 로그인해서 진행 — 1번 코드에 기록 시트 주소와 새 발송 키가 들어가 있어요

    1발송 서버 코드 복사

    이 PC 전용 발송 키가 들어간 코드예요

    2보내는 구글 계정에 서버 만들기 (처음 한 번)

    1. 보내는 계정(예: brightbeed@bead-uni.com)으로 로그인한 상태에서 script.new 열기 (크롬에 계정이 여러 개 로그인돼 있으면 시크릿 창 Ctrl+Shift+N 에서 그 계정 하나만 로그인)
    2. 원래 있던 코드를 지우고 복사한 코드 붙여넣기 → 저장 (Ctrl+S)
    3. 위쪽 함수 선택에서 setup 고르고 ▶ 실행 → 권한 요청에서 모두 선택 → 허용
    4. 오른쪽 위 배포 → 새 배포 → 유형 선택 톱니바퀴에서 웹 앱
    5. 다음 사용자 인증 정보로 실행: 나 · 액세스 권한: 모든 사용자 → 배포
    6. 권한 요청이 뜨면 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용 (내 계정 스크립트라 뜨는 경고예요)
    7. 나온 웹 앱 URL 복사
    연결하면 지금까지 지메일로 보낸 메일도 기록 시트로 자동으로 모으고, 그 뒤로는 1시간마다 새로 보낸 메일을 이어 붙여요.
