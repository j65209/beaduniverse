중국 발주, ERP 연동, 사내 자료 관리를 하나의 화면에서 다룬다.

> **라이브 URL** · https://j65209.github.io/beaduniverse/
> **저장소** · https://github.com/j65209/beaduniverse

## 1. 프로젝트 개요

- **이름** · 브라이트비드 오피스 (Brightbeed Office)

## 9. 업무일지 저장 구조 (v0.5 — 줄 단위 실시간)

업무일지는 **Supabase `diary_items` 테이블에 "한 줄 = 한 행"** 으로 저장된다.
예전에는 전 직원 일지가 `data/diary.json` 파일 하나였고, 한 글자만 고쳐도 파일을
통째로 다시 써서 **동시에 쓰면 남의 줄이 지워지는** 사고가 있었다. 지금은 내가 고친
줄만 서버로 가므로 남의 줄을 덮어쓸 방법 자체가 없다.

| 항목 | 값 |
|---|---|
| 프로젝트 | `브라이트비드오피스` (`ckyjkxbqsyjoqpuqwoce`) |
| 테이블 | `diary_items` (본문) · `diary_item_history` (전 변경 이력) |
| 실시간 | `supabase_realtime` 퍼블리케이션 등록 — 한 줄 고치면 전 직원 화면에 즉시 반영 |
| 백업 | 10분마다 `data/diary.json` 스냅샷 자동 커밋 (사람이 읽을 수 있는 백업) |

### 유실 방지 안전장치 9종

1. **로컬 우선** — 타이핑은 즉시 localStorage 에 저장. 서버 전송은 그 다음.
2. **전송 대기열** — 못 보낸 줄은 대기열에 남고, 대기열도 localStorage 에 보관.
   창을 닫든 인터넷이 끊기든 다음 접속 때 자동 재전송.
3. **시각 도장(`client_ts`)** — 서버 트리거가 더 오래된 편집을 거부한다.
4. **소프트 삭제** — 삭제는 `deleted_at` 표시만. 행은 남는다.
5. **변경 이력** — 모든 변경이 `diary_item_history` 에 자동 적재.
6. **대량삭제 차단** — 한 번에 20줄 넘게 지워지려 하면 중단하고 경고.
7. **GitHub 백업** — 10분 간격 스냅샷.
8. **실시간 + 폴링 이중화** — 실시간 채널이 끊겨도 15초 폴링이 받아온다.
9. **첫 접속 구제** — 예전 방식으로 그 PC 에만 남아 있던 줄을 서버로 한 번 끌어올린다.

### 지워진 줄 복구하는 법

```sql
-- 최근에 지워진 줄 보기
select id, staff_name, day, text, logged_at
from diary_item_history
where deleted_at is not null
order by logged_at desc limit 50;

-- 특정 줄을 되살리기
update diary_items set deleted_at = null, client_ts = extract(epoch from now())*1000
where id = '<줄 id>';
```


## 10. 광고 컨텐츠 스튜디오 (`studio/`)

메타(인스타·페이스북) 릴스·스토리 광고용 **9:16 이미지(1080×1920)** 후가공 툴.
사진 위에 텍스트를 얹고, 실제 릴스·스토리 화면에서 **가려지는 부분(상단 바·브랜드명·캡션·CTA 버튼)** 을
반투명으로 겹쳐 보면서 피해서 배치하고, 같은 디자인으로 **대량 제작**까지 한다.

| 항목 | 내용 |
|---|---|
| 여는 곳 | 홈 → 📂 업무용 툴 → 🎬 **광고 컨텐츠 스튜디오** (새 탭) · 주소 `/studio/` |
| 잠금 | 오피스에서 PIN 을 넣은 브라우저만 열림 (`brightbeed_unlocked`) |
| 저장 | 브라우저 IndexedDB(`bb-content-studio`)에 자동 저장 — **PC·브라우저마다 따로**. 다른 PC 로 옮길 땐 `프로젝트 → 파일로 저장(.bbstudio)` → 다른 PC 에서 `파일 불러오기` |
| 결과물 | 1080×1920 JPG/PNG · 여러 장은 ZIP (UI 시뮬레이션은 결과물에 안 들어감) |

### 주요 기능
- **UI 가림 시뮬레이션** — 지면: 릴스+스토리 공통(기본, 가장 안전) · IG 릴스 · IG 스토리 · FB 릴스 · FB 스토리.
  상단 바·계정명/「광고」·캡션·CTA 버튼(더 알아보기/자세히 보기 등)·우측 아이콘·하단 메뉴를 반투명으로 표시, 불투명도 조절.
  광고 계정은 **beaduniverse** 로 고정(프로필·CTA「더 알아보기」·캡션도 고정, 편집 화면에서 못 바꿈 — `core.js` 의 `AD_PREVIEW`).
- **안전영역** — 메타 권장(1080×1920): 릴스 상단 14%(269px)·하단 35%(672px)·좌우 6%(65px) + 우측 아이콘 줄,
  스토리 상단 14%·하단 약 20%. 글자가 가려지면 빨간 점선 + 상태줄·페이지 썸네일에 ⚠ 경고, 저장 전에도 한 번 더 확인.
- **텍스트** — 자유 이동·크기(모서리=글자 크기, 양옆=줄바꿈 너비)·회전, 글꼴 60종(프리텐다드·G마켓 산스·검은고딕·잘난체 등) +
  **내 폰트 업로드**(TTF/OTF/WOFF, 파일명 `이름-Bold` 로 굵기 자동 인식), 자간·줄간격, 외곽선, 그림자,
  **글자 배경(박스 / 줄마다 하이라이트)**, 고정 너비 + **넘치면 자동 축소**.
- **정렬** — 여러 개 선택 후 왼쪽·가로가운데·오른쪽 / 위·세로가운데·아래 맞춤 (기준: 선택영역·캔버스·안전영역),
  「글자 줄 정렬도 같이」 옵션, 간격 똑같이, 정해진 간격(px)으로 쌓기, 드래그할 때 스냅 가이드(캔버스·안전영역·다른 요소).
- **대량 제작** — 지금 페이지를 템플릿으로, 표(사진 칸·글 칸)에 내용을 채우면 페이지가 한 번에 생성.
  `한 줄 = 1장` 또는 `사진 × 문구 모든 조합`, 엑셀·구글시트 표 그대로 붙여넣기, 줄바꿈은 `//`.
  사진 여러 장을 캔버스에 끌어다 놓아도 「지금 디자인으로 N장」 자동 생성.
  만든 페이지들은 템플릿과 연결돼서 **일괄 수정**(위치·크기·스타일을 한 번에)이 됨.
- 템플릿 6종, 텍스트 스타일 12종, 도형·그라데이션 오버레이, 이미지 위치·확대(더블클릭), 색 보정,
  스타일 복사·붙여넣기(`Alt+Shift+C / V` — 글꼴·색·크기를 다른 글자에 그대로), 되돌리기, 단축키(`?`).

### 파일 구조 (빌드 없음 · ES 모듈)
```
studio/
├── index.html        화면 틀 (잠금 연동)
├── studio.css        다크 에디터 테마
├── js/
│   ├── main.js       시작
│   ├── core.js       상태 · 모델 · 되돌리기 · IndexedDB · 이미지 에셋
│   ├── fonts.js      글꼴 목록 · 지연 로딩 · 내 폰트
│   ├── render.js     텍스트 레이아웃 · 그리기 (편집 화면 = 내보내기 동일 엔진)
│   ├── overlay.js    지면별 안전영역 · 릴스/스토리 UI 목업 · 가림 검사
│   ├── editor.js     캔버스 선택·이동·크기·회전·스냅 · 인라인 텍스트 편집 · 크롭
│   ├── actions.js    추가·삭제·정렬·페이지·일괄 수정
│   ├── panels.js     레이어 목록 · 속성 패널
│   ├── pages.js      페이지 스트립
│   ├── bulk.js       대량 제작
│   ├── exporter.js   PNG/JPG · ZIP · 프로젝트 파일
│   ├── templates.js  템플릿 · 텍스트/도형 프리셋 · 색 견본
│   ├── modal.js      모달 · 메뉴
│   └── ui.js         상단바 · 탭 · 단축키 · 프로젝트 관리
└── tools/
    └── build-artifact.mjs  클로드 아티팩트 판 만들기 (아래 참고)
```
- 배포할 때마다 `studio/index.html` 의 `?v=` 숫자를 전부 올린다 (`studio.css` · `main.js` · import map 의 모듈 목록). 안 올리면 브라우저 캐시(최대 10분)에 옛 모듈이 섞여서 화면이 깨질 수 있다.
- 로컬 확인: 저장소 루트에서 `python3 -m http.server 8765` → `http://localhost:8765/studio/` (오피스에서 PIN 한 번 입력 필요).

### 클로드 아티팩트 판
같은 소스로 클로드(claude.ai) 아티팩트 판도 만든다 — 오피스 밖에서도 클로드 앱에서 바로 열어 쓰는 용도.
- 만들기: `npm i -D esbuild` 후 `node studio/tools/build-artifact.mjs studio-artifact-build`
  → `studio-artifact.html`(JS·CSS 한 파일) + `fonts/`(구글 폰트가 아닌 글꼴 17종 파일) 를 아티팩트로 올림.
- 다른 점: 오피스 잠금(PIN)·「← 오피스」 링크 없음(클로드 공유 권한으로 관리), 저장은 클로드 다운로드 확인창을 거침,
  여러 장은 항상 ZIP, 프로젝트 파일은 `.bbstudio.json` (오피스판에서도 불러오기 됨). 작업물은 그 브라우저에만 저장되는 건 같음.
